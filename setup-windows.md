# 🪟 Windows Setup (WSL Recommended)

## Install Dependencies

- Java 17
- Maven
- WSL Ubuntu

```bash
sudo apt update
sudo apt install openjdk-17-jdk maven -y
```

## GUI Support

- **Windows 11** → WSLg (automatic)
- **Windows 10** → Install [VcXsrv](https://sourceforge.net/projects/vcxsrv/)

Test GUI support:

```bash
xclock
```
